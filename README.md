# Godot Go

This is a plugin for [Godot Engine](https://godotengine.org/) that provides access
to a device's geolocation functionality. It currently supports these operating systems:

- [x] Android
- [ ] iOS
- [ ] Windows

The plugin requires native binaries that have to match the version of Godot used
in a project. The projects that build these can be found here:

- https://github.com/RoboPoets/GodotGo-Android
